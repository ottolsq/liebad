# 阶段 01：边听边看字幕，停止后导出

## 达成情况

- 首版 `0.1.0`：选择麦克风、实测浏览器或抖音桌面客户端，开始后在置顶窗口看到字幕，停止后导出 UTF-8 `.txt`。界面提供三种识别模式，并记住上次选择。
- Agent 验证：首版复核跑过 72 项单元测试和 1 项 Whisper 集成测试。仓库实机记录覆盖真麦克风、Edge 与抖音双源隔离、暂停定稿、关闭目标应用后的重选，以及停止后的文本导出。具体条件和性能见 [测试记录](../test-records.md)。
- 用户反馈：用户说明首版已完成。未单独记录用户亲自操作的逐项结果；以上实测记录不等同于用户对所有场景的验收。

## 未完成及原因

其他浏览器与系统版本未做兼容性验收，不能将本机结果扩展到未测平台。系统混音、文件转写、说话人标签和 TTS 不在首版范围；边界以 [目标与范围](../goal.md) 为准。

## 反馈与处置

模型对比发现中文 wav2vec 2.0 权重在实测样本上出字更快，但中英混说错误率更高。Whisper 保留为默认，wav2vec 2.0 与混合模式可选，结果和限制见 [测试记录](../test-records.md)。

## 风险与遗留问题

首字与定稿耗时取决于音源、模型和本机负载。实测范围不代表跨设备性能保证；本记录也不代表已在干净环境做安装回归或已对外发布。
