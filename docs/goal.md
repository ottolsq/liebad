# 目标与范围

## 问题

现场讲话、抖音桌面客户端和浏览器视频有时缺少字幕。使用者需要边听边读，也希望结束后能保存识别文本，方便回看或搜索。

## 用户

首批用户是需要为现场讲话或 Windows 上播放的视频添加实时字幕，并希望保留转写文字的人。首版以项目使用者的实际场景做验收。

## 目标

- 用户选择一个音源，点击「开始」后，在屏幕顶部的置顶悬浮窗看到实时字幕。
- 首版支持选择麦克风输入设备，或采集抖音桌面客户端和浏览器各自的应用音频。
- 用户点击「停止」后，可以将本次会话的定稿字幕按顺序导出为 UTF-8 `.txt`。

## 非目标

系统混音、游戏适配、本地音视频文件、说话人标签、声纹识别与 TTS 留待后续评估。首版导出格式为 `.txt`。

## 成功标准

| 验收项 | 完成标准 | 验收方法 |
|---|---|---|
| 实时字幕 | 一段连续讲话尚在进行时，置顶悬浮窗已显示临时字幕，随后更新为定稿 | 分别使用麦克风讲话、抖音桌面客户端的视频和浏览器无字幕视频，切换到对应前台场景并记录首次出字延迟、置顶显示和识别效果 |
| 指定应用隔离 | 双音源验证时，只出现所选应用的语音内容 | 让抖音桌面客户端和浏览器同时播放内容不同的语音，分别选中两个应用并检查字幕 |
| 麦克风输入 | 选择可用麦克风后，悬浮窗显示对着该设备说出的内容 | 核对设备名称，对选定麦克风说一段话，检查临时字幕和定稿 |
| 纯文本导出 | 导出文件可按 UTF-8 打开，文字与会话定稿顺序一致，停止前最后一句完成收尾 | 在一句话说完后立即点击「停止」，导出 `.txt`，逐段与会话定稿比对 |

## 约束

首版优先验证中文与常见中英混说。测试设备、浏览器版本、测试媒体和性能基线在开始实测时记录。
